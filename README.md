## 四、 连不上？APN设置与频段兼容自查
　　卡插了，钱付了，重启了… 还是没网？八成是**APN没设对**！这就像给手机配了把钥匙，却忘了告诉它锁孔在哪。
*   **Ncell APN：** `internet` (用户名密码留空)。安卓/iOS手动设置路径不同，提前存个截图教程在手机里很管用。
*   **NTC APN：** `ntc.net` (同样空用户名密码)。

　　手机太老？频段可能不兼容！尼泊尔主要用**3G (2100MHz) / 4G (1800MHz, Band 3)**。出发前查查自己手机型号的支持频段，老旧机型或某些“水土不服”的国行版容易踩雷。*（想象一下，同伴刷得飞起，你的手机却像个砖头… 提前查查吧！）*
